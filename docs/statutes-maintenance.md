# 自治法規系統教學

最後更新：2026-11-17

> **statutes** 為自治法規之英譯，包含本會組織章程與自治法令（組織章程第 61 條參照）。本文件的「法規」即指 statutes；程式與 API 路徑也已統一使用 `statutes`，不再出現 `regulation`／`bylaw`。

## 系統架構

自治法規系統由下列四個部分組成：

| 系統 | 角色 |
| --- | --- |
| Google Drive 共編資料夾「學生自治會法規系統」 | 各單位維護法規**原始檔**（`法規代碼.txt`）的地方，也是正式的資料來源 |
| [NTPU Legislative Database](https://github.com/ntpusu/legislative-data) | 每天從 Google Drive 同步原始檔，兼作備份 |
| GovCloud（本專案） | 讀取 Legislative Database 的資料，提供預覽、列印、修正對照表、**線上法規排版**，以及貼到會網用的資料 |
| [會網](https://ntpusu.ntpu.edu.tw/p/412-1015-227.php?Lang=zh-tw)（RPage CMS） | 對外公開的法規資料庫。**不會自動同步**，須由各單位依本文件「陸」手動貼上 |

```mermaid
flowchart LR
  A[線上法規排版] -- 下載 .txt --> B[Google Drive 原始檔]
  B -- 每日同步 --> C[Legislative Database]
  C --> D[GovCloud 取得各式檔案]
  A -- 依欄位複製 --> E[RPage 會網]
  D -- 依欄位複製 --> E
```

把法規放上會網有兩條路，請擇一：

- **路線一（穩定但拖延）**：在 Google Drive 更新原始檔 → 等待隔日凌晨同步（或手動同步）→ 在 GovCloud「取得各式檔案」開啟該法規的預覽頁 → 依欄位複製到 RPage。會網內容與 Drive、Legislative Database 保證一致。
- **路線二（快速）**：在 GovCloud「線上法規排版」輸入或匯入法規 → 預覽無誤後依欄位複製到 RPage，同時下載 .txt 上傳到 Google Drive。不必等同步，但**若忘記上傳 .txt，或上傳的不是同一份內容，會網就會與 GovCloud 不一致**。採用此路線時，請務必在貼到會網之前，先把 .txt 上傳到 Drive，以避免您忘記。

以下依序說明原始檔格式、各步驟的操作方式。

## 壹、法規原始檔格式

一個法規原始檔由兩部分組成：檔案開頭以 YAML 格式記錄的**基本資料**（以英文欄位名稱開頭的那幾行），以及以純文字記錄的**內文**。

GovCloud線上法規排版功能的「YAML 輸入」模式，可以直接編輯此格式；考量學生自治人員對標記式語法的陌生可能帶來抗拒，我們亦提供「分欄位輸入」模式，把每個欄位拆成獨立的輸入框，才由系統轉成相同的格式。

### 一、基本資料

基本資料的前後各以一行 `---`（三個半形短線）包住，系統才能辨識。各欄位說明如下：

| 欄位 | 說明 |
| --- | --- |
| `titleFull` | 法規全稱，即法規標準法規定之全銜，請勿省略「國立臺北大學學生自治會」前綴。 |
| `titleShort` | 法規簡稱，由主管單位訂定，不含「國立臺北大學學生自治會」前綴；校區單行法規建議冠上「三峽校區」或「臺北校區」。此欄位，就是 Rpage 會網的資訊標題。 |
| `modifiedType` | 最近一次異動的類別：制定、訂定、修正或廢止。 |
| `modifiedDate` | 最近一次異動的日期，以 `YYYY-MM-DD` 格式填寫，例如 `2025-07-30`。會作為會網的發布日期。 |
| `status` | 還有效力的法規填 `active`；已廢止填 `abandoned`。 |
| `history` | 沿革，見下方說明。 |

**沿革**的寫法：

- 每次異動寫一行，依時間先後排列，每行以短線加半形空白「`- `」開頭（在 YAML 中須比 `history:` 多縮排兩個半形空白）。
- 以自治法律為例，每行的組成是「O年O月O日立法機關XX會議通過，O年O月O日行政機關公布（發文字號），\[異動類別]\[異動範圍]。」例如「2025年11月18日三峽校區學生議會第26屆第3次常會通過，會長11月29日公布（峽學字第1141129002號），修正第3條、第6條。」
- 以議會自律規則為例：「2025年7月29日三峽校區學生議會第26屆第2次預備會議通過，7月30日北大峽議授秘字第1140730010號公告，修正第3、4、6條條文。」
- 文字中如有冒號，請使用全形「：」。半形冒號後面接空白（`: `）會讓 YAML 把該行誤認為另一個欄位。

填寫範例：

```yaml
---
titleFull: 國立臺北大學學生自治會三峽校區學生議會學生議員出缺席獎懲規則
titleShort: 三峽校區學生議員出缺席規則
modifiedType: 修正
modifiedDate: 2025-07-30
status: active
history:
  - 2021年8月三峽校區學生議會第22屆第1次臨時會通過，修正部分條文。
  - 2025年7月29日三峽校區學生議會第26屆第2次預備會議通過，7月30日北大峽議授秘字第1140730010號公告，修正第3、4、6條條文。
---

第1條
　（下接內文）
```

### 二、內文

為了讓系統判讀章節、條號、項、款、目，並在會網上以易讀的樣式呈現，請遵循以下格式：

- 章節標題、條號（含條旨）、每一項、每一款、每一目，各自獨立一行。
- **編章節**：直接寫「第X章 標題」、「第X節 標題」，序號與標題以一個空白隔開，不縮排。
- **條號**：直接寫「第X條」（支援阿拉伯數字與中文數字，基於易讀考量建議使用阿拉伯數字），不縮排。條旨以全形括號括註，例如「第X條（主旨）」；不寫條旨時，括號可以省略。
- **項**（及不分項的條文）：每行開頭加**一個全形空白**「`　`」。會網會自動為多項的條文加上項次編號。
- **款、目**：以「`一、`」、「`（一）`」開頭，**不要縮排**（目的括號為全形）。

```text
第一章 總則
第1條
　跨校區自治事務之處理，依本條例之規定。
第2條
　本條例用詞，定義如下：
一、跨校區自治事務：指單一校區無自行處理權限之自治事務。
二、跨校區機關：指總會與學生法院。
第二章 財務
第一節 通則
第3條
　跨校區機關經費之收支與管理，依本章之規定。
……（下略）
```

## 貳、在 Google Drive 維護法規原始檔

請以各單位官方 Google 帳號登入，找到 Google Drive 共用資料夾「學生自治會法規系統」，裡面依單位分成多個資料夾，分別儲存各單位主管的法規。**請只編輯自身單位主管的法規。**

### 一、法規代碼

每部法規以四位數字的**法規代碼**作為檔名，例如 `1101.txt`。第一位數字代表主管機關（決定會網的「負責單位」，見「陸」），第二位數字代表法規粗分類，第三、四位數為流水號（第二至四位數只要不重複，各單位可自行編列）。

**一部法規只會有一個代碼，且不可重複。** 忘記代碼時，可[查看法規清單](https://raw.githubusercontent.com/ntpusu/legislative-data/refs/heads/main/data/bylaw-list.json)（按 Ctrl+F 搜尋），或登入 GovCloud 後點選左側選單「自治法規系統」→「取得各式檔案」。

### 二、原始檔的副檔名與編碼

原始檔一律使用 `.txt`。可以用 Windows 內建的「記事本」開啟、編輯；更方便的做法是使用「線上法規排版」匯入、編輯後再下載（見下述「參」），系統會先檢查格式。

### 三、常見作業

- **修正法規**：下載「法規代碼.txt」，依「壹」的格式修改內容後，上傳取代舊檔。記得同時更新 `modifiedType`、`modifiedDate` 並新增一筆沿革。
- **制定／訂定法規**：編列一個新的法規代碼，製作「法規代碼.txt」上傳到資料夾。
- **廢止法規**：**請不要刪除原有的法規檔**，而是比照修正法規，將 `modifiedType` 改為 `廢止`、`status` 改為 `abandoned`，並把廢止過程寫進沿革，例如「O年O月O日XX會議通過，O年O月O日公布廢止。」

## 參、線上法規排版

「線上法規排版」取代了早期的第 1 版獨立[法規排版工具](https://github.com/ntpusu/ntpusu-regulation-typesetting)，用來撰寫、檢查原始檔，以及產生貼到會網的資料。登入 GovCloud 後，點選左側選單「自治法規系統」→「線上法規排版」。所有處理都在您的瀏覽器中進行，內容不會傳到伺服器。

### 一、輸入

1. 填寫**法規代碼**（四位數字）。下載的檔名、會網的「負責單位」都依此判讀。
2. 選擇**輸入模式**，兩種模式可隨時切換，內容會自動轉換：
   - **分欄位輸入**：每個基本資料欄位各有輸入框。沿革每行寫一筆，不需加「- 」。適合不熟悉 YAML 的使用者。
   - **YAML 輸入**：直接編輯整份原始檔，與 Drive 上的 .txt 格式完全相同。適合從 Drive 複製貼上，或一次修改多處。
3. 修正既有法規時，可按「匯入 .txt 檔」選擇從 Drive 下載的原始檔；檔名是法規代碼時，會自動填入代碼。
4. 內文的項須以全形空白開頭。若輸入法不易打出全形空白，可把游標移到行首後按「插入全形空白」。

YAML 有語法錯誤時，系統不允許切換回分欄位模式（以免內容遺失），請先依檢查結果修正。原始檔中表單沒有的欄位，會原樣保留在下載的檔案中。

### 二、檢查與預覽

畫面右側（手機為下方）會即時列出檢查結果，並顯示會網上的樣子：

- **錯誤**：例如漏填必填欄位、日期格式不對、YAML 語法錯誤。有錯誤時無法複製到會網。
- **提醒**：例如全稱沒有會名前綴、某行無法辨識為章節或條項款目（將原樣輸出、不會排版）、行首使用半形空白。提醒不影響複製，但請逐一確認。

點選檢查結果中的「第 N 行」或欄位名稱，游標會移到該處。

預覽的內容，與貼到會網「資訊詳細內容」的 HTML 完全相同。

### 三、下載備份

按「下載 .txt 檔」，下載的檔案即為原始檔（檔名為「法規代碼.txt」），請上傳到 Google Drive 中貴單位的資料夾，取代舊檔。仍有錯誤時也可以下載，但請修正後再上傳，以免同步失敗。

### 四、草稿

輸入的內容會自動暫存在**這台電腦的瀏覽器**中，關閉分頁後再開啟會自動還原；換電腦或使用無痕模式則不會保留。暫存不是備份，完成後請務必下載 .txt 上傳到 Drive。

## 肆、同步法規到 Legislative Database

本系統 GovCloud 的「取得各式檔案」讀取的是 [NTPU Legislative Database](https://github.com/ntpusu/legislative-data) 的資料，而非直接讀取 Google Drive。

系統約在每天凌晨 2 至 4 時自動從 Google Drive 同步法規原始檔，請避免在這段時間於 Google Drive 維護法規。

若上傳後需要立刻使用，可以手動同步：

1. 以各單位官方 Google 帳號登入 GovCloud（如有更換帳號，請務必通知維護人員）。
2. 點選左側選單「自治法規系統」→「同步自治法規」，按下「立即同步」。
3. 畫面出現帶有打勾符號的說明文字，即表示已觸發同步，約 1 到 3 分鐘後完成。說明文字中的「GitHub Actions」連結可查看進度。

## 伍、在 GovCloud 取得各式檔案

點選左側選單「自治法規系統」→「取得各式檔案」，選擇法規後可以：

- **列印法規**：產生符合《中央法規標準法》的公告版，可另存為 PDF。
- **下載空白修正對照表**：DOCX 檔，供修法提案使用。
- **網頁預覽、貼到 RPage 會網**：預覽會網上的樣子，頁面下方有依 RPage 欄位整理好的資料（見「陸」）。

## 陸、貼到 RPage 會網

會網（RPage）不會自動同步法規。法規制定、修正或廢止後，請由主管單位到會網後台更新。

### 一、操作步驟

1. 開啟要貼上的資料：
   - 路線一：GovCloud「取得各式檔案」→ 點選法規 →「網頁預覽、貼到 RPage 會網」。
   - 路線二：GovCloud「線上法規排版」，確認檢查結果沒有錯誤。
2. 登入 RPage 後台，開啟該法規的「編輯資訊」頁面；新法規請先在對應的法規分類（共通法規、三峽校區法規或臺北校區法規）新增一則資訊。
3. 依下表，在 GovCloud 頁面「貼到 RPage 會網」區塊按下各欄位的「複製」，再貼到 RPage 對應的欄位。
4. 確認無誤後發布，並開啟會網上的頁面檢查一次。

### 二、欄位對照

| RPage 欄位 | 貼上的內容 | 範例 |
| --- | --- | --- |
| 資訊標題 | 法規簡稱（`titleShort`） | 三峽校區學生會組織法 |
| 資訊詳細內容 | HTML 原始碼：法規名稱、最近異動日期、全文、沿革 | （略） |
| 發布日期 | 最近異動日期（`modifiedDate`），`YYYY-MM-DD` | 2025-11-18 |
| 資料更新日期 | 操作當天的日期，`YYYY-MM-DD` | 2026-11-17 |
| 資料檢視日期 | 同資料更新日期 | 2026-11-17 |
| 負責單位 | 依法規代碼第一碼判讀的主管機關，見下表 | 三峽校區學生會 |

貼上「資訊詳細內容」時，請在 RPage 編輯器選擇「HTML」模式，且**不要**開啟「HTML編輯/預覽」，否則編輯器可能改寫原始碼、破壞排版。

### 三、負責單位

| 法規代碼第一碼 | 負責單位 |
| --- | --- |
| 1 | 三峽校區學生會 |
| 2 | 三峽校區學生議會 |
| 3 | 學生法院 |
| 4 | 臺北校區學生會 |

### 四、給會網小組等開發人員：會網的法規樣式

條、項、款、目的縮排與項次編號，由 RPage 全站載入的樣式表 [`regulation-format.css`](https://ntpusu.ntpu.edu.tw/var/file/15/1015/img/16/regulation-format.css) 提供，GovCloud 複製出去的 HTML 只帶 class，不內嵌樣式。若會網上的法規突然沒有縮排或項次編號，請先確認此樣式表是否仍然載入。此樣式表的規則應與本專案的 [`app/assets/css/statutes-format.css`](../app/assets/css/statutes-format.css) 保持一致。

## 附錄：常見問題

**檢查結果說「第 N 筆沿革被解析為物件」？**
該筆沿革中有半形冒號接空白（`: `）。請改用全形冒號「：」，或用單引號包住整行。

**預覽中某些段落沒有縮排？**
該行無法辨識為章節、條號、項、款或目。最常見的原因是項的開頭用了半形空白或 Tab，或忘了加全形空白；款、目則不應縮排。檢查結果會列出這些行的行號。

**會網上的內容與 GovCloud「取得各式檔案」不一樣？**
可能是採用路線二時，貼到會網的內容沒有上傳到 Drive，或 Drive 尚未同步。請以 Drive 上的原始檔為準，重新同步後依路線一更新會網。
